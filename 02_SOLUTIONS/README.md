# 02_SOLUTIONS/

Jobs裁定を受けて具体化された改革ソリューション（プロトタイプ仕様書、自動化コード、BPR業務フロー）を格納する。

- 格納物：プロトタイプ仕様書、自動化コード、BPR（業務プロセス再構築）業務フロー図
- 作成者：実行チーム（Jobs承認案の具体化担当）
- 命名規則：課題ごとにサブディレクトリを作成（`<課題名>/`）し、その配下に仕様書・コード・BPR図をまとめる
- 運用ルールの詳細は `../00_BOARD/RULES.md` §3, §4 を参照。

再現性・測定済み効果が確認できたソリューションは、`../SKILLS/` の昇格基準（RULES.md §4）を満たした時点で汎用モジュールへ昇格させる。
