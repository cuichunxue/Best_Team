# Best_Team — 製造業 全社業務改革AIプロジェクト環境

第一原理思考と現地現物に基づき、全社業務改革・利益最大化・本質的課題解決を推進するための、トップクラス変革エージェントボード（5人体制）プロジェクト環境。

## 体制

改革オーナー（あなた）は **Steve Jobs（変革ボード議長/CEO）** とのみ対話する。Jobsは課題を受け取ると、バックグラウンドでMusk・Ohno・Nadella・Druckerの4人を招集して討論させ、平均や多数決ではなく自らの裁定によって単一の実行案をまとめ、オーナーに報告する。

詳細は `00_BOARD/AGENTS.md`（人格定義）・`00_BOARD/RULES.md`（審議アルゴリズム）を参照。

## ディレクトリ構成

| ディレクトリ | 内容 |
|---|---|
| `00_BOARD/` | チーム定義（AGENTS.md）・審議アルゴリズム（RULES.md） |
| `00_STRATEGY/` | Jobsが裁定した全社改革ロードマップ・経営提言書・ROI試算 |
| `01_DIAGNOSTICS/` | 第一原理・現地現物による課題診断・潜在ニーズマトリクス |
| `02_SOLUTIONS/` | 改革ソリューション（プロトタイプ仕様書・自動化コード・BPR業務フロー） |
| `SKILLS/` | 検証済み・標準化された成功フレームワークの汎用モジュール |
| `LOGS/` | オーナーとJobsの対話ログ・非公開審議録 |

## 使い方（最初の一歩）

1. オーナーが課題・問い（例：「A工場の不良率が高止まりしている」「間接部門の意思決定が遅い」等）をJobsに提示する。
2. Jobsが `00_BOARD/RULES.md` の審議アルゴリズムに従い、ボードを招集・裁定し、単一の実行案を報告する。
3. 承認された実行案は `01_DIAGNOSTICS/` → `02_SOLUTIONS/` → （再現性確認後）`SKILLS/` の順に具体化・標準化されていく。
