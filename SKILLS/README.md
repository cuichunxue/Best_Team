# SKILLS/

ボードの検証を経て標準化された、再利用可能な成功フレームワークの汎用モジュールを格納する。

- 格納物例：QCストーリー監査フレームワーク、信頼性解析モデル、BPR仕様テンプレート等
- 昇格元：`../02_SOLUTIONS/` の個別ソリューションのうち、`../00_BOARD/RULES.md` §4 の昇格基準（再現性／測定済み効果／現地現物検証／捨てる基準の明文化）を満たしたもの
- 命名規則：`<フレームワーク名>/README.md` ＋ 実装（テンプレート、チェックリスト、スクリプト等）

各モジュールのREADMEには、「使うべきケース」だけでなく「使うべきでないケース」を必ず明記すること（Jobsの承認要件）。
