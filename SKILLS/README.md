# SKILLS/

ボードの検証を経て標準化された、再利用可能な成功フレームワーク・プロンプト・分析ロジックの汎用モジュールを格納する、**他部門がオンデマンドで検索・利用できるナレッジデリバリーの単一窓口**。

- 格納物例：QCストーリー監査フレームワーク、信頼性解析モデル、BPR仕様テンプレート、良否判定モデルの前処理・特徴量抽出プロンプト、異常検知の不均衡データ対応ロジック等
- 昇格元：`../02_SOLUTIONS/`（特に `ai_action_learning_program/` のPhase 3）で成果が実証された個別ソリューションのうち、`../00_BOARD/RULES.md` §4 の昇格基準（再現性／測定済み効果／現地現物検証／オンデマンド利用可能な形／捨てる基準の明文化）を満たしたもの
- 自動蓄積の具体的な手順・役割分担は `_INTAKE_PIPELINE.md` を参照。新規登録時は `_TEMPLATE/README.md` をコピーして作成する。
- 命名規則：`<スキル名>/README.md` ＋ 実装（テンプレート、チェックリスト、プロンプト、スクリプト等）

各モジュールのREADMEには、「使うべきケース」だけでなく「使うべきでないケース」を必ず明記すること（Jobsの承認要件）。
