# LOGS/

改革オーナーとJobsの対話ログ、および非公開のボード審議録を格納する。

- 格納物：
  - `YYYY-MM-DD_<課題名>_deliberation.md` — 非公開審議録（Musk/Ohno/Nadella/Druckerの討論生データ、STEP1〜3）
  - `YYYY-MM-DD_<課題名>_report_to_owner.md` — オーナー向け最終報告の控え
- 運用ルールの詳細は `../00_BOARD/RULES.md` §5 を参照。

非公開審議録はデフォルトでオーナーに提示しない。オーナーが明示的に要求した場合のみJobsが要約して開示する。機密情報（未公開財務数値・個人特定可能な人事評価等）はここに直接記載しない。
